# ✨ Overview

DentCare is a premium dental clinic website designed to provide a modern digital experience for patients.

The website combines elegant UI, responsive layouts, and optimized performance to help clinics showcase treatments, doctors, facilities, and appointment information with a professional appearance.

# 🚀 Getting Started

Clone the repository

```bash
git clone YOUR_GITHUB_LINK
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
